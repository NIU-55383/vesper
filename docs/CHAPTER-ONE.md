# VESPER 第一章：无声之地

本次在独立 Vesper 项目内扩展第一章，保留现有奶龙形体、柔润皮肤、一体眼眶、Idle / Walk 接口和教堂建筑风格。运行入口仍为 `/` 与 `/vesper.html`，与桌游网站没有运行依赖。

## 开场与操作

开场采用用户最新图片的构图：近黑空间、顶部单束冷光、细小尘埃、画面中较小的悬浮奶龙。首次移动或开始操作触发镜头靠近和落地，随后在 Stall B 的 B17 附近接管角色；B18 在旁边。探索恢复灰紫、灰蓝与低饱和暗金，开窗不会切换成完整的正常日光色彩。

WASD / 方向键移动；同一前进键 W 或 ↑ 在 280 毫秒内双击并按住第二次可快走，松开停止。W 与 ↑ 不能交叉组合；键盘自动 repeat 不算双击。基础步速保持，快走为 1.7 倍，没有体力或冷却。Shift 保留为辅助操作。E 互动、J 手记、Esc 暂停；鼠标拖动环顾、滚轮调节距离。手机提供摇杆、互动与按住快走按钮。

## 第一章可玩流程

1. 在暗处观察窗帘绳扣，松开短绳锁扣、拉长绳、把绳环固定于挂钩，左侧窗帘打开。帘布、窗光、光束与尘埃随进度变化。
2. 找到 B17 下折叠的节目单，到左侧彩窗对光观察夹层。四个位置显出 `○ △ 空白 ◇`。
3. 在演奏装置跟随约 72 BPM 的四拍输入，第三拍保留空白。错误可以自动重试；成功后以静默、锁扣声、侧室门动作和一次短暂局部色闪反馈。
4. 右侧旧票务间提供 B17 / B18 票、光学票据验证器和可选座位维护记录。穿孔票经桌灯投影，旋钮按投影调整后可开启抽屉。B18 可主动打孔，不弹出好坏评价；票据不会因退出界面而丢失。
5. 抽屉提供 `19:31` 磁带及黄铜钥匙。通过维护窄门进入上层，观察停止的大钟机械并操作磁带。
6. 磁带声音逐渐停止时，卷盘和时间码仍继续。真正播放到结尾才释放主出口连杆；提前停止、倒带、退带都允许再次尝试。
7. 开门前可以继续探索中殿：B18 附近的轻微变化、石板下的低声敲击、条件性可读刻痕。石板始终不开启。
8. 主出口通往灰紫长廊。进入后门缓慢关闭，走到长廊终点结束本章。

整个过程不解释 B18、19:31、色彩变化、声音或物件差异的含义，不显示路线分数。大钟从开场到结束一直停在 19:31，不作为数字密码，也不允许修复。后续路线仅记录倾向，不在本章锁定结局。

## 尚待提供的叙事数据

`vesper/puzzle.mjs` 中 `B18_PRINTED_DATE` 暂为 `null`。用户回复“6月2号”，暂按演出日期配置 `PERFORMANCE_DATE = '06 · 02'`，不添加年份。尚未确认 B18 的具体日期，当前票背保留无具体日期的显示且不计日期观察倾向；这不是已经完成的时间矛盾线索。提供确认的日期后，应替换该配置，并验证它相对于教堂节点确实较晚，不加高亮、解说或自动镜头。

节目单仅列出 Ludovico Einaudi 和 Experience，其余使用 `[Track]` 占位。没有声称这是真实演出的完整节目。拿到实际曲目后可以替换占位，不应把 Experience 特殊标记为任务答案。

原设计目标为首轮探索 20–30 分钟；实际时长仍需要玩家试玩测量，当前不能把目标时长当作已经测得的结果。

## 磁带时间与声音

磁带总长 35 秒，显示时间从 **19:30:35** 走到 **19:31:10**。其中前 12 秒是房间前导段；第 12 秒对应文档示例的 19:30:47，第 25 秒对应 19:31:00。教堂大钟不跟随播放器时间码运行。

| 0–12 秒 | 19:30:35–19:30:47 | 房间前导与细微环境动作 |
| 12 / 17 / 21 秒 | 19:30:47 / 52 / 56 | 纸张、衣料、杯子轻触 |
| 24 秒 | 19:30:59 | 无法辨认来源的轻微吸气 |

音频使用 `vesper/chapter-audio.js` 和 `vesper/assets/audio/chapter1/` 下的原创程序合成 WAV。没有下载、包含或引用 Experience 的版权录音，也没有将歌曲作为解谜前提。`pianoLast` 只是一个原创合成单音。椅子、纸张、衣料等均为合成拟音；其中椅拖声不是实地录音，可日后以获授权或自行录制的固定文件替换。

`terminalChime.wav` 与 `realityChair.wav` 是可跨章节复用的固定资源，不应在后续场景重新随机生成。生成脚本、SHA-256 清单和音频验证报告也随资源保存。声音模块只读取统一的静音与音量偏好；暂停、后台、静音时停止，不在恢复后补播错过的声音。卷盘音在第 25 秒起关闭，故事事件由状态机派发，不靠音频完成回调推进。

## 存档与模块

- `vesper/puzzle.mjs`：版本 2 的纯状态机、前置条件、四拍与磁带计时、隐藏观察记录。
- `vesper/church.js`：座位、窗帘、左侧自然光、侧室、票据机、上层、固定大钟、长廊及分区碰撞。
- `vesper/opening.js`：真实几何光束、开场光照与尘埃。
- `vesper/main.js`：输入、摄像机、交互面板、分区、保存、声音与视觉事件衔接。
- `vesper/chapter-audio.js`：独立章节音频控制，不包含持续背景音乐。

浏览器本地使用 `vesper-save-v2`、`vesper-position-v2` 和 `vesper-started-v2`。旧版三音与反光镜存档不强行解释为新章节进度。读档停止演奏与磁带传输，票据退出机器，关键物品与已完成关卡保留；继续听磁带需要玩家明确操作。

## 运行、检查与部署

使用仓库现有 Node.js 服务，不使用 Go。在仓库根目录运行：

```powershell
npm ci
npm start
```

默认地址 `http://127.0.0.1:18760/`。服务器采用 `PORT` 环境变量，默认监听 `0.0.0.0`；只在本机预览时可设置 `LOCAL_ONLY=1`。停止服务器或重启电脑后需重新启动服务。

```powershell
npm test
npm run test:browser
```

服务器与纯状态机由 `npm test` 检查；浏览器检查需要开发机的 Playwright 与 Chrome，部署不依赖它们。音频专项验证见 `vesper/assets/audio/chapter1/validation.json`，包括 19 个 WAV 原生解码、串行加载、静音/暂停/后台停播、不追补旧音与资源释放。

Render 沿用独立 Node Web Service：Root Directory 留空，Build Command 为 `npm ci`，Start Command 为 `npm start`，Health Check 为 `/healthz`。根目录 `render.yaml` 继续声明 Node 运行时。上传时包含整个 `vesper/assets`、`vesper/vendor` 与新模块，保留目录层级；不用上传 `node_modules`、日志和测试临时文件。本次工作不提交、不推送，也不替用户修改 Render 服务。

## 本轮验收

20 项服务器及纯状态检查通过，扩展浏览器回归 14 组通过、无页面错误。实测覆盖首次移动交接、开场临时骨骼归位、1.7 倍快走、碰撞、四拍空拍、票机分支与退票、真实 35 秒磁带、暂停与重载、长廊关门持久状态、手机 320 / 390 像素操作。开场预热另有专项报告；测试截图和报告位于 `test-results/chapter1/`（开发产物，不作为网页资源公开）。

首次进入的雾类型与灯光数量保持稳定，完整教堂材质在加载页预编译。软件 WebGL 的独立短测记录首次加载 36.02 秒、首次移动交接 3.69 秒，过程无页面错误；这不是所有设备的加载时长承诺。开场结束后临时骨骼偏移清除，模型缩放恢复为 1。专项结果见 `test-results/chapter1/warmup-report.json`。

两秒静默另做真实 WebAudio 专项：确认音频解码完成、琴声正常发出，成功时终止尾音；静默期间关闭面板、实际走动和翻节目单均无新声音，约 2011 毫秒后锁扣声正常恢复。报告和可重跑脚本保存在 `test-results/chapter1/silence-report.json` 与 `silence-check.cjs`。
